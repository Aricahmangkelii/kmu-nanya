# 3D Rock Paper Scissors Showdown 🪨✂️📄

Game Batu Gunting Kertas interaktif berbasis web dengan grafik 3D, efek suara Web Audio API, serta fitur kustomisasi lengkap.

## 🎮 Cara Bermain (How to Play)

1. **Pilih Mode Game**:
   - **VS Komputer**: Bertanding melawan AI.
   - **Berdua (2P Lokal)**: Bermain bergantian dengan teman di satu layar. Pemain 1 memilih terlebih dahulu, lalu disusul Pemain 2.
2. **Level Kesulitan AI**:
   - **Mudah**: Pilihan AI acak.
   - **Sedang**: AI sesekali memprediksi langkah Anda.
   - **Mustahil (Predictive)**: AI menganalisis riwayat gerakan Anda untuk menentukan langkah terbaik.
3. **Aturan Main**:
   - Anda memiliki waktu **10 detik** untuk menekan salah satu tombol pilihan (Batu, Gunting, atau Kertas).
   - Batu mengalahkan Gunting.
   - Gunting mengalahkan Kertas.
   - Kertas mengalahkan Batu.
4. **Visual & Audio**:
   - Hasil pilihan akan muncul dalam model 3D di panggung arena.
   - Efek suara sintetis otomatis berbunyi sesuai hasil pertandingan (Menang, Kalah, Seri, atau Memilih).

## 🚀 Cara Menjalankan di GitHub Pages

1. Upload file `index.html` ini ke repositori GitHub Anda.
2. Buka **Settings** repositori > **Pages**.
3. Pilih branch `main` (atau `master`) dan simpan.
4. Buka tautan URL GitHub Pages yang diberikan untuk mulai bermain!
